# Summary: Milo/Miley V2.0 Full Launch Party Q&A #millenniummachines #opensource #cnc

Source: https://www.youtube.com/watch?v=r6_0nmWxdTk

---

## TL;DR
This is a casual livestream from the **Millennium Machines** team celebrating the public release of the Milo V2 CNC kit's documentation and files (the "Principles" paid-beta phase is complete). Core contributors — DJ Roomba, Phil, Alan (West3D), and developer Kata — take turns showing off side projects: a 4th-axis rotary plugin with probing macros, the upcoming LDO-branded Milo V2 kit, and a ground-up rewrite of the MOS firmware/UI into a plugin-based system called "NXT" with persistent tool libraries and automatic tool-changer (ATC) support. Along the way they cover engineering topics like servo motors vs. steppers, spindle-load monitoring, resonance/input-shaping compensation, and enclosure temperature control. It's mostly banter and live unfinished-software demos rather than a tutorial — useful for tracking Milo/MOS roadmap details, not for learning to build or use the machine.

## Key points
- Milo V2 documentation/files are now publicly live on the website (PDF-based manual, credited to community member "Bright"); a manual link 404 was found and fixed live. [5:27](https://www.youtube.com/watch?v=r6_0nmWxdTk&t=327s), [01:12] area — [10:17](https://www.youtube.com/watch?v=r6_0nmWxdTk&t=617s)
- The upcoming **LDO** Milo V2 kit swaps printed HOI mounts for a CNC'd metal mount and CNC anti-backlash nuts (instead of printed ones); the only holdup before pre-orders is sourcing specific washers. [14:01](https://www.youtube.com/watch?v=r6_0nmWxdTk&t=841s), [14:12](https://www.youtube.com/watch?v=r6_0nmWxdTk&t=852s)
- New standardized print-strength settings — **aesthetic, semi-structural, structural** — are now documented; purely cosmetic parts like the pulley shroud only need the lightweight aesthetic setting (~200–300g). [17:12](https://www.youtube.com/watch?v=r6_0nmWxdTk&t=1032s), [17:35](https://www.youtube.com/watch?v=r6_0nmWxdTk&t=1055s)
- DJ Roomba demoed a new 4th-axis plugin with two probing macros (steps/mm calibration and A-axis flatness correction via a 30mm-offset dual probe), installable through the plugin menu; will be published to Printables/GitHub shortly. [33:00](https://www.youtube.com/watch?v=r6_0nmWxdTk&t=1980s), [34:39](https://www.youtube.com/watch?v=r6_0nmWxdTk&t=2079s)
- MOS is being restructured from one monolithic firmware/UI package into a plugin-based architecture (internally called "NXT"), separating board configuration from the UI plugin so features (4th axis, ATC) ship as independently versioned plugins; original MOS credited to developer "Nine Mile Shoulders." [37:49](https://www.youtube.com/watch?v=r6_0nmWxdTk&t=2269s), [39:22](https://www.youtube.com/watch?v=r6_0nmWxdTk&t=2362s)
- A persistent tool library and ATC magazine-control UI were demoed live: tool data can be exported from Fusion 360 and auto-imported, and RepRapFirmware hard-caps tool count at 50 in its object model (though that's already a lot). [1:00:00](https://www.youtube.com/watch?v=r6_0nmWxdTk&t=3600s), [1:04:37](https://www.youtube.com/watch?v=r6_0nmWxdTk&t=3877s)
- Servo motors are technically supported by RepRapFirmware only via CAN-connected drives; LDO has no confirmed servo/higher-power stepper plans yet, and going below NEMA 23 isn't planned. Phil's "Atlas" project runs a 400W/~780N servo on the X-axis with a 1610 ball screw. [21:24](https://www.youtube.com/watch?v=r6_0nmWxdTk&t=1284s), [54:00](https://www.youtube.com/watch?v=r6_0nmWxdTk&t=3240s)
- Counter to expectations, motor torque is rarely the limiting factor on Milo — machine rigidity, tool deflection, and spindle RPM matter more; heaviest recorded cut pulled 1.8kW. [56:31](https://www.youtube.com/watch?v=r6_0nmWxdTk&t=3391s), [1:09:26](https://www.youtube.com/watch?v=r6_0nmWxdTk&t=4166s)
- No practical way to measure spindle load via accelerometer (ADXL); real CNC machines (e.g., DMG Mori) estimate load via RS485 by checking how well the spindle holds its commanded RPM, not via load cells. [46:37](https://www.youtube.com/watch?v=r6_0nmWxdTk&t=2797s), [47:04](https://www.youtube.com/watch?v=r6_0nmWxdTk&t=2824s)
- A resonance/input-shaping project (led by "Kata") started from tap-testing research and has progressed to live vibration monitoring, reportedly showing visible surface-finish improvements; live filtering may eventually need external compute (Raspberry Pi/RS485 hat) rather than the RRF board alone. [49:22](https://www.youtube.com/watch?v=r6_0nmWxdTk&t=2962s), [50:47](https://www.youtube.com/watch?v=r6_0nmWxdTk&t=3047s)

## Details worth keeping
- 4th-axis mounting options: a "5th Axis" (sic, transcribed "Zindian") 54mm plate bolted direct to a DN85 rotary, or a 52mm zero-point plate for quick tool/fixture swaps. [33:07](https://www.youtube.com/watch?v=r6_0nmWxdTk&t=1987s)
- Tail-stock height for the 4th axis isn't a standard off-the-shelf size — center-line height measured at 62.5mm from the base bottom; an adapter plate could allow a standard live/dead center. [1:13:41](https://www.youtube.com/watch?v=r6_0nmWxdTk&t=4421s)
- Power caveats for US builders: spindles above ~2.2kW are impractical on a standard 110V circuit (leaves no headroom for machine control); 220V is uncommon in US homes outside dryer/welding outlets. [1:09:45](https://www.youtube.com/watch?v=r6_0nmWxdTk&t=4185s), [1:10:00](https://www.youtube.com/watch?v=r6_0nmWxdTk&t=4200s)
- Planned enclosure temp-compensation approach: rather than dynamically compensating for frame temperature, heat the enclosure to a fixed setpoint (e.g., 30°C) via the filter/air system so thermal expansion is always predictable at calibration time. [01:12:xx — cited from block after 01:10:00]
- Touchscreen pendant development is blocked, waiting on Duet to ship a Duet-branded touchscreen unit. [1:13:41](https://www.youtube.com/watch?v=r6_0nmWxdTk&t=4421s)
- The 4th-axis beta will follow the same release pattern as Milo V2: paid "Principles" beta first, then free beta, then fully public release. [1:14:59](https://www.youtube.com/watch?v=r6_0nmWxdTk&t=4499s)
- A CNC calibration test part ("Ben CNC," sic) — a circle/diamond/square accuracy test — is suggested as a good first-machining project, sized to fit 50mm square stock. [1:14:59](https://www.youtube.com/watch?v=r6_0nmWxdTk&t=4499s)

## Skip it if
You want a tutorial on building, tuning, or operating a Milo — this is unstructured dev-team/community banter and live demos of unreleased software, not instructional content.
