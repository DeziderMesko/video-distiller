# Summary: Tiny Box Miley Enclosure Ep2 #millenniummachines #opensource #cnc

Source: https://www.youtube.com/watch?v=sbp-t1ARIxI

---

TL;DR
This is a community livestream from the Millennium Machines open-source CNC/3D-printer project, mostly build-log footage of the "Tiny Box" enclosure (renamed "Casita" mid-stream) — a scaled-down version of the "Casa" enclosure, sized for the Miley machine rather than the larger Milo. Alongside the fabrication (panels, filters, magnets, keystone jacks), the host previews early CAD work on Atlas, a much larger dual-electronics-bay CNC still in beta, and talks through firmware, tooling, and workshop opinions with regular chat members. It's casual and conversational — long stretches of dog talk, jobs, motorcycles, and D&D — with only intermittent hands-on technical content.

## Key points
- "Tiny Box" is officially renamed "Casita" during the stream — it's the miniaturized Casa-style enclosure for Miley, buildable smaller because Miley (unlike Milo) doesn't move side to side [7:19](https://www.youtube.com/watch?v=sbp-t1ARIxI&t=439s), [1:20:16](https://www.youtube.com/watch?v=sbp-t1ARIxI&t=4816s), [2:13:03](https://www.youtube.com/watch?v=sbp-t1ARIxI&t=7983s).
- Casita's frame uses only 4 unique extrusion lengths (all 700mm) versus Casa's many different lengths, and roughly half the fastener count (~50 M5x10, ~100-200 M3x10) compared to Casa Rev2's 300+ M3s alone; the design is also mirrorable without any slicer/CAD mirroring step [37:48](https://www.youtube.com/watch?v=sbp-t1ARIxI&t=2268s), [1:05:25](https://www.youtube.com/watch?v=sbp-t1ARIxI&t=3925s), [2:13:16](https://www.youtube.com/watch?v=sbp-t1ARIxI&t=7996s), [2:13:33](https://www.youtube.com/watch?v=sbp-t1ARIxI&t=8013s).
- Host estimates Casita's total BOM cost at about half of the original Casa enclosure, in a noticeably smaller footprint (two Casitas fit where one old Casa did) [1:58:55](https://www.youtube.com/watch?v=sbp-t1ARIxI&t=7135s).
- The host's Voron Trident, plagued by unresolved inconsistent-extrusion problems for months (swapped Octopus board, toolboard, Nitehawk extruder board, tried Galileo extruder, went full direct-drive hardwire — nothing fixed it), is being handed off to a community member (Jake/Jose) to rebuild as a production machine; host believes the fault is self-inflicted mods, not the original LDO kit [18:44](https://www.youtube.com/watch?v=sbp-t1ARIxI&t=1124s), [21:03](https://www.youtube.com/watch?v=sbp-t1ARIxI&t=1263s), [25:55](https://www.youtube.com/watch?v=sbp-t1ARIxI&t=1555s).
- Atlas (the project's larger CNC) update: full 20mm plate construction, 1610 ball screws throughout, a 500×350×140mm working envelope inside a 1.1m-wide dual-electronics-bay enclosure (for separating things like LinuxCNC computers or water-cooling from VFDs/electronics) [2:04:53](https://www.youtube.com/watch?v=sbp-t1ARIxI&t=7493s), [2:12:08](https://www.youtube.com/watch?v=sbp-t1ARIxI&t=7928s).
- Live poll in chat during the stream unanimously favored Atlas's older, more "visible-motion" enclosure aesthetic over the newer, more practical one — the tradeoff being about 30mm of lost X-axis travel for the nicer-looking option [2:20:48](https://www.youtube.com/watch?v=sbp-t1ARIxI&t=8448s).
- Host strongly prefers Marlin (on their new Prusa Core One) over Klipper for pre-built/production printers because it "just works" with no config faff; separately notes that enabling sensorless homing on a Klipper Voron shifts the true home position (~5mm) with almost no documentation on how to correct it [53:52](https://www.youtube.com/watch?v=sbp-t1ARIxI&t=3232s), [59:31](https://www.youtube.com/watch?v=sbp-t1ARIxI&t=3571s), [1:00:22](https://www.youtube.com/watch?v=sbp-t1ARIxI&t=3622s), [57:51](https://www.youtube.com/watch?v=sbp-t1ARIxI&t=3471s).
- Bambu Lab gripe: with an AMS attached, the printer refuses to reprint a job in ABS-GF if the loaded print profile was for plain ABS, even though both print at the same speed — Prusa's slicer just asks the user to confirm material and lets them proceed regardless [53:52](https://www.youtube.com/watch?v=sbp-t1ARIxI&t=3232s), [55:00](https://www.youtube.com/watch?v=sbp-t1ARIxI&t=3300s).
- Millennium Machines software roadmap: moving Atlas's control pendant from a Pi+screen Linux setup to Duet's newly-released onboard display over CAN; RepRapFirmware doesn't natively support tool-changers (it treats every tool as a separate "spindle"), so the team is building custom tool-management UI/GitHub docs to handle it [49:59](https://www.youtube.com/watch?v=sbp-t1ARIxI&t=2999s), [1:44:50](https://www.youtube.com/watch?v=sbp-t1ARIxI&t=6290s).
- 5-axis CNC is judged not worth pursuing for hobbyists right now — the hardware is buildable, but CAM software licensing (~$2,000/year) is the real barrier [1:21:39](https://www.youtube.com/watch?v=sbp-t1ARIxI&t=4899s).

## Details worth keeping
- Filtration design for the enclosure: needs a multi-stage filter — first knock coolant mist back to liquid, then absorb oils, then carbon for smell — because plain carbon pellets would saturate with oil-based coolant almost instantly [1:06:54](https://www.youtube.com/watch?v=sbp-t1ARIxI&t=4014s).
- Never laser-cut or heat vinyl/PVC — it releases chlorine gas; UV lasers are considered safe for vinyl (ablation, not melting), but Bambu's H2D laser is LED-based, not UV, so avoid vinyl in it [1:30:00](https://www.youtube.com/watch?v=sbp-t1ARIxI&t=5400s).
- Shrink-fit ER16 tool holders solve tool-drop issues with collet-based tool-changers but cost roughly £100/$100 each from Cutwell (UK); cheaper workaround suggested is adding O-rings to standard collets [1:51:36](https://www.youtube.com/watch?v=sbp-t1ARIxI&t=6696s), [1:52:31](https://www.youtube.com/watch?v=sbp-t1ARIxI&t=6751s).
- A DIY CNC plasma cutter can reportedly be built for well under $300, since the plasma torch/gun is the expensive part, not the motion system [1:35:12](https://www.youtube.com/watch?v=sbp-t1ARIxI&t=5712s), [1:35:45](https://www.youtube.com/watch?v=sbp-t1ARIxI&t=5745s).
- Host's own cost benchmarks: first Milo build ~$850; an MPCNC build ~$600 including a 500W spindle [1:38:47](https://www.youtube.com/watch?v=sbp-t1ARIxI&t=5927s).
- Duet's new integrated control pendant/screen is now purchasable at some vendors and connects over CAN; the team was expecting one donated by Duet for development [49:59](https://www.youtube.com/watch?v=sbp-t1ARIxI&t=2999s), [50:49](https://www.youtube.com/watch?v=sbp-t1ARIxI&t=3049s).
- A separate vacuum-table accessory (led by a contributor "Phil") is planned to fit the V2, V1.6, and V1.5 kits [2:12:38](https://www.youtube.com/watch?v=sbp-t1ARIxI&t=7958s).

## Skip it if
You're not already following the Millennium Machines project (Milo/Miley/Atlas/Casa) — this is a long, chatty community livestream with light fabrication content and no step-by-step tutorial value for outsiders.
